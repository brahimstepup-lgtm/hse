# Politique de confidentialité — Safety Tags

*Dernière mise à jour : 14 novembre 2026*

Safety Tags est une application qui aide les équipes HSE à créer des fiches d'anomalie (« Safety Tags ») à partir d'une photo.

## Données traitées
- **Photos et textes des tags** que vous saisissez.
- **Noms et adresses email** des personnes que vous ajoutez dans les Réglages.
- **Réglages** (listes, règles, URL de votre script, jeton, clé API facultative).

## Où vont ces données
- **Sur votre téléphone** : par défaut, tout est enregistré uniquement dans l'espace privé de l'application.
- **Votre Google Sheet / Google Drive (optionnel)** : si vous connectez votre propre script Google Apps Script, les tags et photos sont envoyés à votre compte Google, et à aucun autre serveur.
- **Anthropic (optionnel)** : si vous ajoutez votre propre clé API et touchez « Remplir avec l'IA », la photo et la note sont envoyées à l'API d'Anthropic pour générer une proposition de texte. Voir https://www.anthropic.com/legal/privacy.
- **Emails et partage** : l'application ouvre votre application d'email (par ex. Outlook) ou le menu de partage ; rien n'est envoyé sans votre action.

Le développeur de l'application ne collecte, ne reçoit et ne vend aucune donnée. Aucune publicité, aucun traçage, aucune analyse d'usage.

## Suppression
Désinstaller l'application supprime toutes les données stockées sur le téléphone. Les données envoyées dans votre Google Sheet ou Drive restent sous votre contrôle dans votre compte Google.

## Contact
Pour toute question : utilisez l’adresse de contact indiquée sur la fiche Google Play de l’application.

# Privacy policy — Safety Tags (English)

Safety Tags stores the tags, photos, contacts and settings you enter **on your device**. Optionally, it sends them to **your own** Google Sheet/Drive through a script you deploy, and, only if you add your own API key and tap "Fill with AI", sends the photo and note to the Anthropic API. The developer collects no data; there are no ads, analytics or tracking. Uninstalling the app deletes all on-device data. Contact: see the developer email on the Google Play listing.
